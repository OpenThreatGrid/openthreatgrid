# Security Policy

## Supported Versions

OpenThreatGrid is currently in early MVP development. No stable production version has been released yet.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory or contacting the maintainer.

Do not publicly disclose vulnerabilities until they have been reviewed.

## Responsible Use

OpenThreatGrid is intended for defensive security research, threat intelligence, honeypot operation, and education. Do not use this project to attack or disrupt third-party systems.
