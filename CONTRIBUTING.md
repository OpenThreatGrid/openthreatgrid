# Contributing to OpenThreatGrid

Thank you for your interest in contributing.

## Contribution Areas

- Honeypot sensor deployment
- Parser development
- Event schema improvements
- Threat intelligence report templates
- Grafana dashboards
- Kubernetes manifests
- Documentation
- Safe operation guidance

## Development Principles

- Defensive use only
- Privacy-conscious telemetry
- Clear documentation
- Safe defaults
- Kubernetes-friendly deployment

## Pull Request Checklist

Before submitting a pull request:

- Add or update documentation.
- Avoid including secrets or real sensitive logs.
- Include sample data only if it is sanitized.
- Explain the security impact of the change.
