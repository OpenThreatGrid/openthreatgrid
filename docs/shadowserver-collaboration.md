# Shadowserver Collaboration Plan

OpenThreatGrid is not affiliated with Shadowserver Foundation. This document describes a possible future collaboration path after the project has a working MVP and safe data handling process.

## Goal

Prepare OpenThreatGrid telemetry and documentation so it can be useful to broader public-benefit cybersecurity efforts.

## What OpenThreatGrid Can Offer

- Regional honeypot telemetry from Indonesia and Southeast Asia.
- Normalized event schema.
- Aggregated statistics about brute-force, scanning, botnet, and malware delivery attempts.
- Weekly public intelligence reports.
- Community-operated sensor documentation.

## What OpenThreatGrid Should Ask For

- Feedback on safe honeypot operation.
- Feedback on data anonymization.
- Guidance on useful event formats.
- Guidance on what telemetry is most useful for public-benefit reporting.
- Possible future integration or collaboration direction.

## Minimum Requirements Before Outreach

Before contacting Shadowserver, OpenThreatGrid should have:

- Working Cowrie sensor deployment.
- At least 2-4 weeks of telemetry.
- A sample weekly report.
- A documented data policy.
- A documented safety model.
- A clear statement that public outputs are aggregated and sanitized.
- A technical architecture document.
